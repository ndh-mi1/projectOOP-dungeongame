# THƯ MỤC THEO DÕI LỖ HỔNG KIẾN THỨC (UNDERSTANDING GAPS)
<!-- Cập nhật: 2026-11-19 | Sở hữu: Cả hai (Nguyễn Đình Huy & Nguyễn Công Huy) -->

Thư mục này ghi lại các câu hỏi hoặc chủ đề kiến thức mà sinh viên chưa trả lời đạt yêu cầu trong các buổi diễn tập `/teach-back` hoặc `/defense-rehearsal`.

## 1. QUY TRÌNH XỬ LÝ LỖ HỔNG KIẾN THỨC
1. Khi sinh viên trả lời sai hoặc lúng túng trước một câu hỏi $B \rightarrow A, \Delta, W$, Agent tạo một file ghi chú lỗi trong thư mục này (đặt tên: `YYYY-MM-DD_TVx_<chủ đề>.md`).
2. Ghi rõ:
   - Câu hỏi được đặt ra.
   - Câu trả lời chưa hoàn chỉnh của sinh viên.
   - Phân tích nguyên nhân gốc rễ và tài liệu cần đọc lại.
   - Bài tập ôn tập hoặc câu hỏi kiểm tra lại.
3. Trong phiên làm việc tiếp theo, Agent sẽ ưu tiên đặt lại câu hỏi này. Khi sinh viên trả lời xuất sắc, file sẽ được đánh dấu `RESOLVED` và nâng mức trong sổ `TVx_ledger.md`.

## 2. TRẠNG THÁI HIỆN TẠI
- Hiện tại chưa phát hiện lỗ hổng kiến thức nghiêm trọng nào (0 open gaps).
