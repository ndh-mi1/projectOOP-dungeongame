3. *Value Object vs Entity:* Trả lời nắm được ý cốt lõi. Bổ sung chuẩn học thuật: Entity (class) có định danh duy nhất (Id) và vòng đời; Value Object (struct) bất biến, định danh bằng giá trị và nằm trên Stack tránh áp lực GC. (Đạt)
