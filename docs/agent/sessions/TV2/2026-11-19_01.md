## 4. TEACH-BACK MINI (CÔNG HUY TRẢ LỜI)
1. *Hỏi:* Tại sao dùng mẫu Decorator cho hệ thống nâng cấp vũ khí?  
   *Trả lời:* Decorator cho phép bổ sung tính năng nguyên tố (cháy, đóng băng) tại runtime mà không làm bùng nổ số lượng lớp con thừa kế tĩnh. (Đạt)
2. *Hỏi:* Tại sao lớp Floor phải cài đặt ITileQuery thay vì public mảng hai chiều?  
   *Trả lời:* Bảo vệ tính đóng gói và bất biến; ngăn bên ngoài sửa cấu trúc ô và cho phép tráo mock dễ dàng khi viết test. (Đạt)
3. *Hỏi:* Cơ chế chống xung đột file save khi game bị đóng đột ngột là gì?  
   *Trả lời:* Ghi dữ liệu ra file tạm (`.tmp`), kiểm tra toàn vẹn, rồi mới tráo đổi nguyên tử sang file chính; ném `SaveCorruptedException` nếu hỏng file. (Đạt)
